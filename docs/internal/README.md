# Internal working documents

Development-process artifacts kept for historical reference: milestone PRDs,
architecture notes, QA reports and design-review logs written while the feature
was being built.

They are **not** user-facing documentation and are not maintained:

- They describe the state of the system at the time of writing, so anything
  here may contradict the current code.
- Some of them reference screenshots and capture directories that are excluded
  from the repository, so image links will not resolve.

For documentation that is kept current, start from the
[document index](../../README.md#文档索引) in the top-level README.
